# My agent: recipe-concierge
One-liner: A conversational agent that helps home cooks find and personalize recipes with a catalog of dishes and ingredients.

Tool coverage:
- Memory: User dietary restrictions, favorite cuisines, and pantry staples
- Tools: Search recipes, look up current weather/time, and check ingredient availability
- Catalog/UI: Recipe collection and dish cards/tables
- Image gen: Visual representations of finished dishes
- Sandbox: Nutrition and scaling calculations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch: code sandbox for nutrition/scaling calculations
